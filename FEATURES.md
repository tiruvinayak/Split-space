# Features

- Simulated local authentication/session, profile editing and logout
- Local-first group create/edit/delete, member management and invitation records
- Expense create/edit/delete with search, filters, sorting and CSV export
- Recurring daily/weekly/monthly/yearly schedules with next due dates and duplicate-safe generation
- Local JPEG/PNG/WebP/GIF/PDF receipt preview, replace/remove and size validation
- Equal, percentage and custom allocations with validation
- Integer-paise rounding and debt simplification
- Pending and confirmed simulated settlements with balance updates
- State-derived dashboard/admin analytics, charts and transaction exports
- Persistent notification preferences, mark-read/delete notification center
- Dark/light theme, responsive navigation, accessible modal interactions

Actual payment, backend authentication and admin security are not included. Browser viewport review remains unverified; see `TEST_RESULTS.md`.
